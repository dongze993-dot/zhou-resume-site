# Interactive Resume Website

A responsive, single-page portfolio website built with plain HTML, CSS, and JavaScript. It presents experience evidence through role-based navigation, structured project cards, and lightweight interactive effects.

## Highlights

- Responsive layout for desktop and mobile browsers
- Role-focused navigation that links skills to relevant experience
- Evidence-based project and experience cards
- Keyboard-friendly controls and print-to-PDF support
- Static assets only: no build step, framework, or runtime dependency

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Deploy

Publish this folder to a static hosting provider such as GitHub Pages or Cloudflare Pages/Workers.

## Project structure

```text
.
├── assets/       # Visual assets
├── index.html    # Page content and structure
├── styles.css    # Visual system and responsive layout
├── app.js        # Navigation and interaction behavior
└── robots.txt    # Search-engine crawl preference
```

## Content updates

Update the page content in `index.html` before deployment. Keep public repository metadata focused on the website as a front-end project rather than personal profile details.
